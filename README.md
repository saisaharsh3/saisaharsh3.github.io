# saisaharsh3.github.io

Holds `.well-known/assetlinks.json`, which lets Android open [Leftovers](https://github.com/saisaharsh3/Leftovers) links (a friend's money-owed link, `saisaharsh3.github.io/Leftovers/add#…`) straight in the app. It lists the app's public signing-key fingerprint, the same one F-Droid checks. The website itself is at [saisaharsh3.github.io/Leftovers](https://saisaharsh3.github.io/Leftovers/).
